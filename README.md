# One-Lane Car Parking System

The **One-Lane Car Parking System** is a C++ project that demonstrates the use of the **Stack (LIFO — Last In, First Out)** data structure to manage cars entering and leaving a one-lane parking area.

Because cars can only leave from the same side they entered, the system uses a stack to represent the parking lane.

## Features

*  Add a car to the parking lane
*  Remove a car from the parking lane
*  Display parked cars
*  Track parking order
*  Demonstrates Stack (LIFO) operations

##  Technologies Used

* C++
* Stack Data Structure
* Object-Oriented Programming

##  Data Structure

This project uses a **Stack** based on the **LIFO (Last In, First Out)** principle.

The last car that enters the parking lane is the first car that can leave.

```text
Parking Lane

[ Car 3 ] ← Last In / First Out
[ Car 2 ]
[ Car 1 ]
──────────
 Entrance / Exit
```

##  Purpose

The main purpose of this project is to demonstrate how a **Stack data structure** can be applied to a real-world situation.
